# Agentic Profile Matching

A local candidate-search and screening assistant implemented as a LangGraph state
machine. It reads resume files from a folder, extracts job criteria, retrieves and ranks
the top candidates, explains strengths and gaps, and supports follow-up comparisons,
interview questions, and requirement refinements.

## Setup

Python 3.10+ is recommended.

```powershell
python -m pip install -r requirements.txt
```

Three synthetic sample resumes are included in `resumes\` so the demo runs immediately.
Replace them with `.txt`, `.md`, `.pdf`, or `.docx` resumes (or provide another
directory). Candidate names are derived from file names. Resume content is processed
locally; this project does not send candidate data to an external model or service.

## Run

```powershell
python app.py --resume-dir resumes
```

Example conversations:

- `Find candidates with React and 3+ years experience`
- `Compare the top 3 matches side by side`
- `Why did Alex rank higher than Sam?`
- `Generate screening questions for Alex`

After a search, enter additional criteria at the refinement prompt to re-rank the
shortlist. Enter an empty response to continue. Type `quit` to exit.

## Workflow and deliverables

- LangGraph implementation and state: [matching_agent.py](./matching_agent.py)
- Interactive CLI: [app.py](./app.py)
- State-machine diagram: [STATE_DIAGRAM.md](./STATE_DIAGRAM.md)
- Five conversation-flow tests: [tests/test_matching_agent.py](./tests/test_matching_agent.py)
- Timed demo recording script: [DEMO_SCRIPT.md](./DEMO_SCRIPT.md)
- Offline narrated MP4 generator: [tools/create_demo_video.py](./tools/create_demo_video.py)

To create the 5–6 minute narrated demo video on Windows, install the requirements
and run `python tools/create_demo_video.py`. It uses Windows' built-in offline
speech synthesis and the included fictional resumes; pass an output path to save the
MP4 elsewhere. The generator runs the sample agent flows and tests to prepare the
on-screen results.

The first round retrieves up to 100 resumes by lexical relevance; detailed ranking and
recommendations are run on the top 10. Scoring uses only job-related evidence available
in resume text and flags missing evidence instead of inferring protected characteristics.
The output is screening support, not a substitute for human hiring decisions.

Run tests with:

```powershell
python -m unittest discover -s tests -v
```

The generated reports can be used to record a demo. A video file is not generated by
this repository.
